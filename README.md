# Password Security Checker

A Python-based tool that checks the strength of a password using
basic security criteria and provides a security score.

## Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Detects commonly used passwords
- Provides a password strength score

## Technologies Used

- Python
- Basic Cybersecurity Concepts

## How It Works

The program analyzes the password based on different security
conditions and assigns points for each condition satisfied.
Based on the total score, the password is classified as Weak,
Medium, or Strong.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python password_checker.py

5. Enter a password when prompted.

## Purpose

This project was developed to understand basic password security,
Python programming, and password strength evaluation.
